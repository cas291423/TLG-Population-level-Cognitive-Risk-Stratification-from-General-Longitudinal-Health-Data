# TLG: Tree-guided Local-Global Trajectory Profiling

This repository provides reproducibility materials for the manuscript:

**“Population-level cognitive risk stratification decision support from general longitudinal health data: Tree-guided local-global trajectory profiling.”**

Tree-guided Local-Global Trajectory Profiling (TLG) is a longitudinal risk-inference framework developed for population-level cognitive risk stratification using general health information without prior cognitive scores. The framework is designed for broad but temporally sparse and irregular longitudinal health records and integrates population-level risk modeling, local and global trajectory representations, and outcome-bearing evidence from analogous historical cases.

## Currently available materials

The current public release contains three methodological documentation files:

### Repository Table R1
**Predictor schema, health-domain assignment, and wave-specific structural availability**

This file provides the complete general-health predictor set used in the study, the corresponding health-domain assignments, and the structural availability of each predictor across the CHARLS survey waves.

### Repository Table R2
**Evaluation protocol and model configuration details**

This file documents the shared evaluation and training protocol and the principal configuration and hyperparameter settings used for the tree-based and deep temporal comparison models.

### Repository Table R3
**TLG computational configuration and information-isolation rules**

This file provides the detailed computational specification of TLG, including the construction of the final 66-dimensional representation, Local, Global, and tree-contribution trajectory representations, analogous-case retrieval settings and statistics, validation-selected parameters, and information-isolation procedures.

## Code and data availability

At the current stage, this repository publicly provides only the three methodological documentation files listed above.

To avoid premature disclosure of unpublished research materials during the manuscript review process, the complete source code and additional reproducibility materials will be released in this repository at a later stage following completion of the publication process.

Data used in this study were derived from the **China Health and Retirement Longitudinal Study (CHARLS)**. Any future release of processed data or data-related materials will comply with the applicable CHARLS data-use and redistribution requirements.
